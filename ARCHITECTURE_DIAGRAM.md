# Architecture Diagram

## 🏗️ Clean Architecture Structure

```
┌──────────────────────────────────────────────────────────────────┐
│                         FRONTEND DASHBOARD                        │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐

│  • No business logic                                              │

                               ↓
┌──────────────────────────────────────────────────────────────────┐

│  ├── useAutoArticleForm() - AI form management                   │

│  └── useAutoDialog() - AI dialog state                           │

                               ↓
┌──────────────────────────────────────────────────────────────────┐
│                         DATA LAYER (RTK Query)                    │
│  API Hooks from @/app/store/api                                   │
│  ├── useGetArticlesQuery()                                        │
│  ├── useCreateArticleMutation()                                   │
│  ├── useUpdateArticleMutation()                                   │
│  └── useDeleteArticleMutation()                                   │
└──────────────────────────────────────────────────────────────────┘
                               ↓
┌──────────────────────────────────────────────────────────────────┐
│                         BACKEND API                               │

└──────────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────┐
│                         CONFIGURATION LAYER                       │
│  config/ - Declarative configurations                             │
│  ├── columns.tsx - Table column definitions                       │

│  └── gridItems.tsx - Stats grid definitions                       │

┌──────────────────────────────────────────────────────────────────┐
│                         COMPONENT LAYER                           │
```

## 🔄 Data Flow

```
USER INTERACTION
     ↓
┌─────────────────┐
│  page.tsx       │ ← User clicks "Create Article"
│  (UI Layer)     │
└─────────────────┘
     ↓ Calls handler
┌─────────────────┐
│  useArticles.ts │ ← handleCreateOrUpdate()
│  (Logic Layer)  │
└─────────────────┘
     ↓ Calls mutation
┌─────────────────┐
│  RTK Query      │ ← useCreateArticleMutation()
│  (Data Layer)   │
└─────────────────┘
     ↓ HTTP Request
┌─────────────────┐
│  Backend API    │ ← POST /api/articles
│                 │
└─────────────────┘
     ↓ Response
┌─────────────────┐
│  RTK Query      │ ← Cache updated, UI refreshed
│  (Data Layer)   │
└─────────────────┘
```

## 💡 Key Concepts Illustrated

### 1. **Separation of Concerns**
```
┌──────────┐   ┌──────────┐   ┌──────────┐
│   UI     │   │  Logic   │   │   Data   │
│  Layer   │ → │  Layer   │ → │  Layer   │
└──────────┘   └──────────┘   └──────────┘
   Clear         Clear         Clear
   Focus         Focus         Focus
```

### 2. **Dependency Inversion**
```
High Level    →    Abstraction    ←    Low Level
(Component)        (Interface)         (API)

page.tsx    →    useArticles()   ←   RTK Query
```

### 3. **Open/Closed Principle**
```
Base Hook: useFeaturePage()
    ├── ✅ Open for extension (add new hooks)
    └── ✅ Closed for modification (stable interface)
```
